# Учись со мной

Приложение Учись со мной. (VK Mini App- app54835047) - это пространство для спонтанной совместной учебы. Пользователи создают учебные комнаты по конкретным темам (например, «Физика, задача №5», «Разбор главы по истории», «Кодим проект на Python»), которые отображаются в общей ленте. Любой желающий может зайти в открытую комнату в один клик и присоединиться к занятию. Внутри комнаты доступны общая интерактивная доска, голосовой чат и совместный плейлист VK Музыки. Модератор комнаты управляет составом участников и их правами на доске, а система помогает находить напарников по предмету и статусу онлайн в реальном времени.
